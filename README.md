# MathBot — превью

Описание того, как устроен телеграм-тренажёр по математике и смекалке для 5–6 классов,
и банк заданий входной диагностики.

Здесь только статическая страница. Исходный код бота, ключи и персональные данные
учеников находятся в отдельном приватном репозитории и сюда не попадают.

Страница закрыта от индексации поисковиками (`robots.txt` + `noindex`).

Собирается автоматически:
- `data/grader-demo.json` — фактический вывод проверяльщика ответов;
- `data/bank.json` — банк диагностики, каждое задание перерешано независимо.
